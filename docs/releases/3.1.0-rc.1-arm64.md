# Codifix 3.1.0-rc.1 ARM64 Linux candidate

This distribution is an unsigned ARM64-only prerelease for Debian 12 compatible
systems. It is not the complete multi-platform stable release and does not change
GitHub's latest stable release. The source snapshot excludes private deployment
runbooks and internal review records. It includes the corresponding Rust, SQL,
web, packaging and dependency-lock source needed to build the package.

Five AArch64 executables, Debian 12 dependency/symbol compatibility and QEMU
version/help/startup checks are validated. Native ARM installation, application
login and production configuration are separate acceptance steps. Package
installation does not start services or create grants. Back up an existing
database and use the established owner migration/cutover procedure before
starting the candidate. The optional identity broker is not included; its known
upstream advisory remains unresolved.
