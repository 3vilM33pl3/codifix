# Codifix 3.1.0

Codifix 3.1.0 adds Linux desktop session and area routing support, specialist
task coordination, and private Network and Inbox workflows. The specialist
runtime supports reviewed Linear work, incident handling, SSH certificate
renewal, and OpenBao ceremonies. These workflows require explicit enrollment,
operator configuration, and the relevant permissions. See the [specialist
guide](https://github.com/3vilM33pl3/codifix/blob/v3.1.0/docs/user/autonomous-specialists.md) and the [Network and Inbox guide](https://github.com/3vilM33pl3/codifix/blob/v3.1.0/docs/user/network-inbox.md).

- [Linear project tracking](https://github.com/3vilM33pl3/codifix/blob/v3.1.0/docs/user/cli/linear.md) links approved task
  checkpoints and verified completion to an enrolled Linear project. A
  separate terminal workflow lets operators review and correct drafts before
  approval.
- [Incident response](https://github.com/3vilM33pl3/codifix/blob/v3.1.0/docs/user/incident-response.md) records independently
  verified recovery and links reviewed follow-ups from the postmortem. The
  opt-in canary exercise verifies the incident, Inbox, and Linear receipts.
- [CA companion upgrades](https://github.com/3vilM33pl3/codifix/blob/v3.1.0/docs/user/companion-release-rollout.md) show staged
  release evidence and upgrade progress in the terminal. OpenBao phone
  ceremonies check private notice enrollment before accepting contributions.

## Upgrade from 3.0.0

The database migrations after `0085` are additive and run through `0105`.
Back up the existing PostgreSQL database and preserve the instance configuration
before upgrading. Use the same database and instance configuration when starting
the new service. Verify readiness and read back existing project data after
restart. The Debian stable version `3.1.0` sorts after the `3.1.0~rc.N` packages.
For older Memory Layer installations, follow the separate [Codifix 3 reinstall
procedure](https://github.com/3vilM33pl3/codifix/blob/v3.1.0/packaging/CODIFIX-3-REINSTALL.md).

## Packages

- **Linux:** Debian amd64 and arm64 packages use the Debian 12 ABI. PostgreSQL
  with pgvector is a separate prerequisite. The Linux desktop app is versioned
  and distributed separately.
- **macOS:** Intel and Apple Silicon standard and application-update packages
  are available. The standard installer requires a separately provisioned
  PostgreSQL runtime. The application-update package preserves the existing
  Codifix runtime. Check the release inventory for signing and notarization.
- **Windows:** The x86_64 ZIP, per-user MSI and server-tools MSI are preview
  packages. Installer build `4` reports MSI version `3.1.4`. The packages are
  unsigned. The optional PostgreSQL, PDS, and Pi runtimes are provisioned separately.
  The Windows PDS runtime has its own validation workflow.

## Verify downloads

Use `release-inventory.json` to identify the build commit and artifact metadata.
Check each download against `SHA256SUMS` and its individual checksum. The
Homebrew formula pins the stable source archive by checksum.
