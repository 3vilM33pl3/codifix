# Codifix 3.0.0

Codifix 3.0.0 is the stable release of the renamed product. Verify every
download against the published `SHA256SUMS` and individual checksum files, and
use `release-inventory.json` to identify the exact source commit and artifact
metadata. The source commit is intentionally taken from that inventory rather
than inferred from a tag or version string.

## Changes since the release candidate

This release includes the fixes completed after v3.0.0-rc.1: Mac handoff boolean
serialization and fresh-device binding, active agent-bootstrap behavior and MCP
tool naming, journal lock release, and CI fixture reliability. The release
continues to include database migrations through 0085; it adds no migrations
beyond 0085.

Codifix 3 is a breaking technical rename from Memory Layer. Existing Memory
Layer installations require a reviewed reinstall and recovery procedure; the
packages do not perform an in-place product migration. Preserve and verify a
matched recovery set before a cutover. See the
[reinstall procedure](../../packaging/CODIFIX-3-REINSTALL.md) and
[release compatibility guide](../user/release-compatibility.md).

## Platform packages and limits

- **Linux:** Debian packages are available for amd64 and arm64. Debian filenames
  use `codifix_3.0.0_ARCH.deb`. PostgreSQL with pgvector is a separate
  prerequisite.
- **macOS:** Intel and Apple Silicon standard and application-update packages
  are available. They are unsigned and not notarized. Standard packages do not
  bundle PostgreSQL; application-update packages preserve the existing Codifix
  runtime they update.
- **Windows:** x86_64 ZIP, MSI and server-tools MSI packages are preview
  artifacts. The MSI is build 2 and uses MSI version 3.0.2. Windows remains a
  preview and does not include a complete PostgreSQL/PDS/Pi stack. Windows
  packages are unsigned.

Homebrew remains HEAD-only until the stable formula is pinned after the source
asset is published. The native Mac onboarding journey remains an optional
separately scoped capability; its guide records its acceptance limits. No broad
native parity or live-upgrade claim is made.

## Verify

Download assets only from the
[Codifix 3.0.0 release](https://github.com/3vilM33pl3/codifix/releases/tag/v3.0.0).
Check `SHA256SUMS`, the matching sidecar checksum, and the release inventory
before installing. Checksums establish content consistency, not publisher
identity.
