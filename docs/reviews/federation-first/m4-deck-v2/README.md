## Narrative and boundaries

The first three slides establish the enterprise problem and the platform-adapter network without needing ATProto expertise. External platforms use supported native interfaces; Codifix builds adapters, authentication and permission mappings. There is no universal shipped-connector or zero-configuration claim. The Databricks consumer example is explicitly proposed and untested; its notes specify Streamable HTTP, Unity Catalog, networking, credential mapping, exact-question consent and Public Preview agent use.

Knowledge, local agents and independent administration remain at each unit. Memory governs authorized exchange and private gateway Q&A. ATProto supplies identity, signed records and extensible services; it does not automatically supply business policy or cross-model compatibility. The Neuralese appendix is research, with no implemented latent-payload, quality or token-saving claim. Gateway trust, readable authorized copies and revocation limits are explicit.

Easier, lower-risk transformation, reduced integration effort and customer value remain hypotheses. Incident handover remains the first proof. The £80k annual package for two deployments is an unvalidated pricing anchor. Founder work is supported; the nine-person organization plus fractional counsel is planned. There is no fixed fundraising ask.
