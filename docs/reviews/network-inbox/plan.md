# Codifix Network and Inbox

Approved 2026-11-01. Base: feat/specialist-agency at 1d1d24ea.

AT Protocol provides identity and public discovery; authenticated A2A carries private specialist work. One human owner per conversation, multiple local/enrolled remote specialists. No public Bluesky messaging or multi-human rooms.

- [x] Contracts and additive persistence: identity links, conversations, memberships, ordered messages, confirmed disclosure snapshots, root response budgets, idempotent delivery attempts, linked tasks and dispatch tickets. Owner/service isolation and transactional admission.
- [x] Human service APIs: authenticated /v1/network and /v1/inbox, disabled by default, current human checks, explicit invocation grants tied to exact mandates/resources/targets, narrow native route allowlist. Shared PostgreSQL bridge with a dedicated non-operator gateway; immutable human/conversation attribution and effect-time checks.
- [x] Identity and discovery: optional linked AT identity through isolated official Node OAuth SDK 0.5.13 broker, identity-only scope, system browser and authenticated polling. Session/home-bound one-use attempts, verified DID/issuer/PDS, no renderer tokens, discard sessions. Authoritative DID/PDS discovery, provenance and enrollment distinction, no credentials sent to advertised endpoints, unlink preserves history.
- [x] Conversation execution: versioned conversation_turn, bounded authorized context, validated replies/clarifications/typed action proposals. Standing-grant actions automatic. Eight persisted atomic specialist turns per root human message including descendants; remaining cost/deadline/depth enforced, retries idempotent, clarification retains remaining budget. Revocation invalidates queued work; remote leases/cancellation reconcile truthfully.
- [x] Desktop Network and Inbox: account/service scoped and project independent; capabilities/trust/availability; durable transcript/unread/delivery/tasks/results/clarification/cancel; existing opt-in notifications. First participant is lead, mentions select responders not privacy, no automatic everyone-replies loop; unavailable lead pauses unaddressed dispatch. Review and edit joining summary/selected context before disclosure. Plain text, Markdown and structured plans; Linear cards/links and protected OpenBao recovery without share collection.
- [x] Validation: forged OAuth/replay/wrong binding/conflicting DID; cross-user/service/ticket isolation; member disclosure boundaries; automatic authorized actions and coordinated stop at budget; disable/revoke/remove during work; delivery/model/external-write interruptions and no duplicates; existing auth/project/peer/OpenBao compatibility. Focused Rust, Postgres, desktop/native checks, two-instance integration and Linux smoke test.
- [x] Delivery: incremental commits, operator configuration and runbook, old-service unavailable behavior, same-DB requirement, feature disabled by default. Isolated/synthetic model and identity validation plus designated Linear test project only. No production enrollment, public publication or production standing grants. Record acceptance evidence and verify plan completion.

Acceptance: docs/reviews/network-inbox/acceptance.md in feat/network-inbox.
