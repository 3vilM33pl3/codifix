# Codifix

Codifix gives coding agents persistent, project-scoped memory. It captures decisions, context, and rationale from each session, curates them to remove duplicates and noise, and stores the results in a graph and vector database so future sessions can recall what matters and how it connects. Frequently used memories are re-validated against your code, so what agents recall stays accurate as the project moves. It works with Codex, Claude Code, OpenCode and the OpenAI, Voyage and Ollama embedding APIs.

**Memory Layer is being renamed to Codifix.** The 3.0.0-rc.1 candidate is not
published yet, so its packages are not available to install. The published
[v2.1.0 release](https://github.com/3vilM33pl3/codifix/releases/tag/v2.1.0)
is the previous Memory Layer product; there was no Codifix v2.0 or v2.1
release. Existing installations should read the [update guide](/docs/install/update)
before planning a cutover.
