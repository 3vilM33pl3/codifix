# Codifix

Codifix helps developers and coding agents carry useful knowledge between
sessions. Capture a decision or fix, keep its evidence, and retrieve it later
with citations through the CLI, TUI, browser or MCP.

Start with one local project. When configured, **knowledge areas** keep separately
operated knowledge distinct, teams share reviewed material privately, and laptops
retain selected knowledge for offline use. A project query stays within its
selected instance; sharing or asking another area is an explicit workflow.

These docs follow current `main`. Codifix v3.0.0 is available. Windows remains a preview. Match installed package bytes to the release inventory and its source commit.
Memory Layer v2.1.0 is the previous product. See
[release compatibility](/docs/help/known-limitations) and
[Update](/docs/install/update) before changing an existing installation.
