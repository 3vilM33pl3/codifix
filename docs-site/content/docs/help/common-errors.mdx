# Common errors

![Codifix errors tab](/images/tui/errors-tab.png)

## `connection refused`

The service or database is not reachable at the configured address.

Fix: check service status, database host, port, firewall, and config.

## `extension "vector" is not available`

pgvector is not installed on the PostgreSQL server.

Fix: install the server-side pgvector package and run `CREATE EXTENSION IF NOT EXISTS vector;`.

## `codifix command not found`

The package install path is not on `PATH`, or the install failed.

Fix: open a new shell, check the package install, and run `codifix --version`.

## `Project not configured`

The current repository has not been initialised for Codifix.

Fix: run `codifix wizard --dry-run` and then `codifix wizard` from the project root.

## Verify

For duplicate `codifix_*` tools, keep one MCP connection: disable a hand-authored
server entry when enabling the desktop plugin. For expertise submission denied
as read-only, check the explicit operator policy and exact-question approval;
ordinary memory access does not authorize a remote ask. See [MCP](/docs/mcp).

If a named instance still reports an older release after a restart, inspect its
selected configuration and pinned release. Restarting does not upgrade it.

```bash
codifix doctor
codifix status --project <project-slug>
```
