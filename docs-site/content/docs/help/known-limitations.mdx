# Known limitations

Codifix 3.0.0-rc.1 is an unpublished release candidate. Its Debian, macOS, and
Windows packages are not available to install yet. The published v2.1.0 release
is the previous Memory Layer product; no Codifix v2.0 or v2.1 release exists.
See the [Update guide](/docs/install/update) before moving an existing install.

## Rename and state boundary

The rename changes package and runtime identities. Installing Codifix does not
automatically adopt Memory Layer configuration, state, or services. The
release-specific reinstall procedure covers the explicit cutover and
reconciliation work. Semantic memory records, canonical IDs, and area topology
are intended to be preserved through that reviewed process.

## Platform limits

| Platform | Current status |
|---|---|
| Debian/Ubuntu | Candidate package names are defined for amd64 and arm64; candidate downloads are not published. |
| macOS | Candidate Intel and Apple Silicon packages are defined; native Intel validation remains a release gate. Homebrew has a HEAD formula only, with no stable pinned formula yet. |
| Windows | Candidate x86_64 ZIP/MSI and server-tools MSI are preview artifacts; they are not published. The packages do not provide full Windows parity or a complete native PostgreSQL/PDS/Pi stack. Windows ARM64 is not a release target. |

The macOS application-update package applies only to an existing Codifix
installation. It does not migrate Memory Layer. The Windows server-tools MSI
is a machine-level scaffold; it does not provision dependencies or start
services.

## Other limitations

| Surface | Limitation |
|---|---|
| Loop automation | Approval-gated by design; risky actions stop for human review. |
| Code graph UI | Falls back to a flat 2D canvas renderer without WebGL; depends on extraction coverage for each repository. |
| Eval research workflows | Release claims still require reviewed held-out suites and a passing gate. |
| Demo web UI | Uses browser-local sample data and is not a live backend. |

## Database migrations

Database migrations are append-only. The service contains migrations through
0085 and applies pending application migrations at startup. These migrations
do not perform the Memory Layer-to-Codifix identity cutover. Do not run an old
Memory Layer binary against a database after Codifix has accepted writes.

Read [Update](/docs/install/update), [Operations](/docs/operations), or [Doctor and health](/docs/help/doctor-and-health).
