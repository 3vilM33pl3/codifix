# From source

## What you will do

Run a development copy from this repository while keeping it isolated from any packaged install.

## Steps

```bash
cargo run --bin codifix -- init
cargo run --bin codifix -- dev --copy-from-global
cargo run --bin codifix -- service run
```

In another terminal:

```bash
cargo run --bin codifix -- tui
```

The dev profile uses different ports and runtime paths from the installed service. The TUI header includes `[dev]` when connected to the dev stack.

## Verify

```bash
CODIFIX_PROFILE=dev cargo run --bin codifix -- health
CODIFIX_PROFILE=dev cargo run --bin codifix -- doctor
```
