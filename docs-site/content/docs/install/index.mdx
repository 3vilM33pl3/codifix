# Install

The [3.0.0-rc.1 prerelease](https://github.com/3vilM33pl3/codifix/releases/tag/v3.0.0-rc.1) is available. Do not
use the one-line installer for this candidate: until a Codifix stable release
is available, it deliberately refuses to select the older Memory Layer
release. The existing v2.1.0 release is still published under the Memory Layer
product and package identity; it is not a Codifix installer or an upgrade path.

The Codifix candidate introduces a breaking product rename. Installing it over
an existing Memory Layer setup does not transfer its state. If you are moving
an existing installation, read the [Update guide](/docs/install/update) and
the [release-specific reinstall procedure](https://github.com/3vilM33pl3/codifix/blob/main/packaging/CODIFIX-3-REINSTALL.md).

## Candidate package names

Download these packages from the [release page](https://github.com/3vilM33pl3/codifix/releases/tag/v3.0.0-rc.1) and verify
them against its [SHA256SUMS](https://github.com/3vilM33pl3/codifix/releases/download/v3.0.0-rc.1/SHA256SUMS).

| Platform | Candidate asset names |
|---|---|
| Debian/Ubuntu | `codifix_3.0.0~rc.1_amd64.deb`, `codifix_3.0.0~rc.1_arm64.deb` |
| macOS | `codifix-3.0.0-rc.1-macos-x86_64.pkg`, `codifix-3.0.0-rc.1-macos-aarch64.pkg`, and matching `-application-update.pkg` packages |
| Windows x86_64 | `codifix-3.0.0-rc.1-windows-x86_64-build.1.zip`, `.msi`, and `-server-tools.msi` |

GitHub changes `~rc.1` to `.rc.1` in Debian download filenames. Follow the
[Linux download commands](/docs/install/linux-debian) to save the original
names before checksum verification; the package bytes are unchanged.

## Prerequisites

Codifix requires a PostgreSQL database with the pgvector extension enabled.
See [PostgreSQL and pgvector](/docs/install/postgresql-pgvector) for setup
instructions. Optional LLM and embedding providers improve curation and
semantic retrieval, but the core service works without them.

| Requirement | Why it matters | Verify |
|---|---|---|
| PostgreSQL | Durable storage for projects, captures, memories, activity, and history. | `psql "$DATABASE_URL" -c "SELECT 1;"` |
| pgvector | Vector storage for semantic retrieval. | `psql "$DATABASE_URL" -c "SELECT extversion FROM pg_extension WHERE extname = 'vector';"` |
| Codifix 3.0.0-rc.1 candidate | Renamed CLI and service tooling; prerelease packages available. | After installation: `codifix --version` |

## Configure after installation

```bash
cd /path/to/project
codifix wizard --dry-run
codifix wizard
codifix doctor
codifix health
```

The dry run previews setup actions before files or services are changed. See
[Service setup](/docs/install/service-setup) and [Doctor and health](/docs/help/doctor-and-health).
