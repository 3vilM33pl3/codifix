# Install

Joining an existing organization? Start with [Team setup](/docs/team-setup) and
your administrator's approved company origin. The standalone installation below
creates and configures your own service/database; it is a different journey.

Codifix v3.0.0 is the current stable release. ([v3.0.0](https://github.com/3vilM33pl3/codifix/releases/tag/v3.0.0)). The existing v2.1.0 release remains under the Memory Layer product identity; it is not a Codifix installer or upgrade path.

The Codifix release introduces a breaking product rename. Installing it over
an existing Memory Layer setup does not transfer its state. If you are moving
an existing installation, read the [Update guide](/docs/install/update) and
the [release-specific reinstall procedure](https://github.com/3vilM33pl3/codifix/blob/main/packaging/CODIFIX-3-REINSTALL.md).

## Stable package names

Download these packages from the [release page](https://github.com/3vilM33pl3/codifix/releases/tag/v3.0.0) and verify
them against its [SHA256SUMS](https://github.com/3vilM33pl3/codifix/releases/download/v3.0.0/SHA256SUMS).

| Platform | Release asset names |
|---|---|
| Debian/Ubuntu | `codifix_3.0.0_amd64.deb`, `codifix_3.0.0_arm64.deb` |
| macOS | `codifix-3.0.0-macos-x86_64.pkg`, `codifix-3.0.0-macos-aarch64.pkg`, and matching `-application-update.pkg` packages |
| Windows x86_64 | `codifix-3.0.0-windows-x86_64-build.2.zip`, `.msi`, and `-server-tools.msi` |

Debian filenames use `codifix_3.0.0_ARCH.deb`. Verify packages against the release checksums.

## Prerequisites

Codifix requires a PostgreSQL database with the pgvector extension enabled.
See [PostgreSQL and pgvector](/docs/install/postgresql-pgvector) for setup
instructions. Optional LLM and embedding providers improve curation and
semantic retrieval, but the core service works without them.

| Requirement | Why it matters | Verify |
|---|---|---|
| PostgreSQL | Durable storage for projects, captures, memories, activity, and history. | `psql "$DATABASE_URL" -c "SELECT 1;"` |
| pgvector | Vector storage for semantic retrieval. | `psql "$DATABASE_URL" -c "SELECT extversion FROM pg_extension WHERE extname = 'vector';"` |
| Codifix 3.0.0 | Stable packages available; Windows remains a preview. | After installation: `codifix --version` |

## Configure after installation

```bash
cd /path/to/project
codifix wizard --dry-run
codifix wizard
codifix doctor
codifix health
```

The dry run previews setup actions before files or services are changed. See
[Service setup](/docs/install/service-setup) and [Doctor and health](/docs/help/doctor-and-health).
