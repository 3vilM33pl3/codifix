# Install

Joining an existing organization? Start with [Team setup](/docs/team-setup) and
your administrator's approved company origin. The standalone installation below
creates and configures your own service/database; it is a different journey.

For a new service, install the current stable release, [v3.1.0](https://github.com/3vilM33pl3/codifix/releases/tag/v3.1.0). If you already run Codifix 3.0.0, back up the existing database and configuration and follow the [3.1 upgrade steps](/docs/install/update#upgrade-codifix-300-to-310). Memory Layer v2.x installations have a [separate reinstall procedure](https://github.com/3vilM33pl3/codifix/blob/v3.1.0/packaging/CODIFIX-3-REINSTALL.md).

## Stable package names

Download these packages from the [release page](https://github.com/3vilM33pl3/codifix/releases/tag/v3.1.0) and verify
them against its [SHA256SUMS](https://github.com/3vilM33pl3/codifix/releases/download/v3.1.0/SHA256SUMS).

| Platform | Release asset names |
|---|---|
| Debian/Ubuntu | `codifix_3.1.0_amd64.deb`, `codifix_3.1.0_arm64.deb` |
| macOS | `codifix-3.1.0-macos-x86_64.pkg`, `codifix-3.1.0-macos-aarch64.pkg`, and matching `-application-update.pkg` packages |
| Windows x86_64 | `codifix-3.1.0-windows-x86_64-build.4.zip`, `.msi`, and `-server-tools.msi` |

The Linux packages above contain core service and client tools. See [Linux Desktop](/docs/desktop) for the separately versioned graphical client.

## Prerequisites

Codifix requires a PostgreSQL database with the pgvector extension enabled.
See [PostgreSQL and pgvector](/docs/install/postgresql-pgvector) for setup
instructions. Optional LLM and embedding providers improve curation and
semantic retrieval, but the core service works without them.

| Requirement | Why it matters | Verify |
|---|---|---|
| PostgreSQL | Durable storage for projects, captures, memories, activity, and history. | `psql "$DATABASE_URL" -c "SELECT 1;"` |
| pgvector | Vector storage for semantic retrieval. | `psql "$DATABASE_URL" -c "SELECT extversion FROM pg_extension WHERE extname = 'vector';"` |
| Codifix 3.1.0 | Stable packages available; Windows remains a preview. | After installation: `codifix --version` |

## Configure after installation

```bash
cd /path/to/project
codifix wizard --dry-run
codifix wizard
codifix doctor
codifix health
```

The dry run previews setup actions before files or services are changed. See
[Service setup](/docs/install/service-setup) and [Doctor and health](/docs/help/doctor-and-health).
