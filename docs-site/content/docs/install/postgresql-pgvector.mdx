# PostgreSQL and pgvector

## What you will do

Create a dedicated database, enable pgvector, and verify the connection Codifix will use.

## Steps

```bash
sudo -u postgres createuser --pwprompt codifix
sudo -u postgres createdb --owner=codifix codifix

export DATABASE_URL='postgres://codifix:<password>@127.0.0.1:5432/codifix'
psql "$DATABASE_URL" -c "SELECT 1;"
psql "$DATABASE_URL" -c "CREATE EXTENSION IF NOT EXISTS vector;"
psql "$DATABASE_URL" -c "SELECT extversion FROM pg_extension WHERE extname = 'vector';"
```

Use a hosted PostgreSQL instance if you prefer, but confirm that the provider supports pgvector and that your network policy allows the Codifix service to connect.

## Verify

```bash
codifix doctor
codifix health
```

## Troubleshooting

- `extension "vector" is not available`: install pgvector on the PostgreSQL server, not just the client machine.
- `permission denied to create extension`: ask a database administrator to enable `vector` or grant the needed privilege.
- `connection refused`: check host, port, TLS, firewall, and service status.
