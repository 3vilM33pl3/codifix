# Linux / Debian

The [Codifix v3.1.0 release](https://github.com/3vilM33pl3/codifix/releases/tag/v3.1.0) provides Debian 12 ABI packages for the core service and CLI. See [Linux Desktop](/docs/desktop) for the graphical client.

## Debian package names

The stable package names are:

- x86_64: `codifix_3.1.0_amd64.deb`
- arm64: `codifix_3.1.0_arm64.deb`

The arm64 package is for 64-bit Debian-family systems, including Raspberry Pi
4/5. 32-bit Raspberry Pi OS is not a release target. Verify downloads against
the release [SHA256SUMS](https://github.com/3vilM33pl3/codifix/releases/download/v3.1.0/SHA256SUMS) before installing.

## Install

Install PostgreSQL with pgvector first, or use a reachable PostgreSQL server
with the `vector` extension enabled. Then download the package for your
architecture, verify its checksum, and install it:

```bash
curl -fL -o 'codifix_3.1.0_amd64.deb' 'https://github.com/3vilM33pl3/codifix/releases/download/v3.1.0/codifix_3.1.0_amd64.deb'
curl -fL -o 'codifix_3.1.0_amd64.deb.sha256' 'https://github.com/3vilM33pl3/codifix/releases/download/v3.1.0/codifix_3.1.0_amd64.deb.sha256'
sha256sum -c 'codifix_3.1.0_amd64.deb.sha256'
sudo dpkg -i codifix_3.1.0_amd64.deb
```

Replace `amd64` with `arm64` in all commands on 64-bit ARM.
The Debian package version is `3.1.0`. For an existing service, follow the [Update guide](/docs/install/update) before installing. It covers both the Codifix 3.0.0 database upgrade and the separate Memory Layer v2 cutover.

After installation, configure and check the service:

```bash
codifix wizard --global
cd /path/to/project
codifix wizard --dry-run
codifix wizard
sudo systemctl enable --now codifix.service
codifix doctor
codifix health
```

## Verify

```bash
codifix --version
systemctl status codifix.service
codifix status --project <project-slug>
```

## Troubleshooting

- `codifix command not found`: open a new shell or check the package install path.
- `connection refused`: verify the service is running and the configured port matches.
- `extension "vector" is not available`: install the pgvector package for your PostgreSQL major version.
