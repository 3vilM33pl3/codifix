# Linux / Debian

The Codifix 3.0.0-rc.1 Debian packages are not published yet. The current
published v2.1.0 release installs the previous Memory Layer product and is not
a Codifix package. The one-line installer intentionally refuses to select that
legacy release while no Codifix stable release is available.

## Candidate package names

Once published, the release assets are expected to be:

- x86_64: `codifix_3.0.0~rc.1_amd64.deb`
- arm64: `codifix_3.0.0~rc.1_arm64.deb`

The arm64 package is for 64-bit Debian-family systems, including Raspberry Pi
4/5. 32-bit Raspberry Pi OS is not a release target. These filenames do not
currently identify published artifacts. Wait for the release page and matching
checksums before installing.

## Install after publication

Install PostgreSQL with pgvector first, or use a reachable PostgreSQL server
with the `vector` extension enabled. Then download the package for your
architecture from the published Codifix 3.0.0-rc.1 release, verify its
published checksum, and install it:

```bash
sudo dpkg -i codifix_3.0.0~rc.1_amd64.deb
```

Use the `_arm64.deb` filename on 64-bit ARM. The candidate is a breaking
product rename. If replacing an existing Memory Layer install, follow the
[Update guide](/docs/install/update) and the
[release-specific reinstall procedure](https://github.com/3vilM33pl3/codifix/blob/main/packaging/CODIFIX-3-REINSTALL.md)
before installing; `dpkg` does not migrate that installation's state.

After installation, configure and check the service:

```bash
codifix wizard --global
cd /path/to/project
codifix wizard --dry-run
codifix wizard
sudo systemctl enable --now codifix.service
codifix doctor
codifix health
```

## Verify

```bash
codifix --version
systemctl status codifix.service
codifix status --project <project-slug>
```

## Troubleshooting

- `codifix command not found`: open a new shell or check the package install path.
- `connection refused`: verify the service is running and the configured port matches.
- `extension "vector" is not available`: install the pgvector package for your PostgreSQL major version.
