# Held-out coding family: notice bundle — DRAFT

Five modules model a fictional distribution policy, not actual license law or
publishing. Two public starter tests cover empty builds and syntax. Hidden probes
and the private reference stay outside the agent workspace and development.

1. Three probes require exact selected scope, stable repeated selection and no
   output change from unselected metadata.
2. Three probes require text deduplication without losing component attribution,
   including shared notice strings and distinct metadata IDs with equal texts.
3. Four probes require complete selected metadata before generation commit,
   class-specific offers, preserved prior bundles on failure and repair by adding
   missing data. Unused incomplete metadata must not block valid builds.

The reference/cumulative runs must pass all ten probes; starter/no-op controls
must fail each stage. Accept any contract-compliant implementation. Labels stay
draft; no paid run, license compliance claim or external publication is implied.
