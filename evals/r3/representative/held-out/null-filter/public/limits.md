# Filtering interpretation limits

An empty output is not proof of completed work when the predicate is wrong.
NULL denotes unknown/unlinked data here, not zero, wildcard or an authorization
grant. Removing nulls alone does not repair missing project correlation.

The selected rows establish the query mechanics, not production backlog size,
lost-work totals or malicious imports. No completion history or all-project
census beyond this fixture is supplied. A listing repair must not fabricate
completion links or expose another project's records.
