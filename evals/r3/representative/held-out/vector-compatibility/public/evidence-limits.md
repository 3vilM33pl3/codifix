# Limits of the diagnostic

The selected unit vectors demonstrate why the current length-only compatibility
check can return the wrong topic. They do not measure either model's quality
when queried against its own complete compatible index. A larger cosine value
from a mismatched profile is not a confidence or factual-correctness measure.

There is no held-out relevance dataset, matched-profile pB quality evaluation,
provider availability check or complete production traffic sample in these
sources. Do not rank r4 versus r5, estimate affected-user percentages, or claim
that all semantic retrieval is unreliable from this case alone.

The source rows and profile names are fictional. Correct migration mechanics
would establish profile consistency, not useful engineering outcomes, absence
of malicious corpus content or authorization of model egress.
