# Color interpretation limits

Under the toy model, a's intensity is about 0.252, while b's is about 0.502.
c approximates a after integer quantization; it is not an exact continuous-value
identity. A second Q-to-P transform on P data changes meaning again.

This diagnoses sample/profile handling, not physical monitor accuracy, real
color-standard conformance or subjective image quality. Equal raw bytes do not
prove equal interpreted pixels. There is no full-image quality metric, display
calibration, actual ICC implementation or production asset census here.
