# Search interpretation limits

The sample demonstrates field loss, substring false matches and limit-before-
authorization starvation. Excluding a result after limiting prevents that row's
display but still can hide valid local results. These are separate concerns.

No production retrieval metrics, complete access audit or diagnosis correctness
labels beyond the selected lookup rule are supplied. A lexical match establishes
the query predicate, not truth, authority or permission to run imported text.
Do not claim global search quality from five synthetic records.
